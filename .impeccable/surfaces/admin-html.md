# Surface: admin panel (admin.html)

Scope: owner's control panel plus store cabinet and agency cabinet in one file (role switcher). Mode: Operate. Device: laptop first (sidebar + tables), collapses to a phone layout. Users: non-technical owner; store managers; agency managers. Structure from the TZ: stories (per store + YouTube Shorts life hacks, 24h), storefront editor (photos/addresses, map, hours, managers with phone/e-mail/MAX/TG, payment & delivery, services, per-store filters), bulk import 1C/Excel with column mapping, shared-card matching and photo archive, store cabinet adding 1–5 products with moderation, sections management, real estate (agencies with manager logins; commercial with filters), accounts. New sections are clickable with sample data; existing functions keep saving to data.js.

## Direction contract

THESIS: The back office of the same marketplace: one calm work surface where the owner always sees what needs attention next. Refuses the old amber gradient header, emoji labels and colored stat tiles.

OWN-WORLD: Inherits DESIGN.md: #F2F3F6 ground, white borderless cards, Onest, ink #0B1A2E, single action blue #1259F5, magenta-red only for problems/sale, green only for "published". Desktop adds a white left sidebar, dense row tables with hairline separators, right-side editor drawers, segmented controls in ink.

STORY: Owner opens Обзор, sees a "Требует внимания" list, clears moderation, imports a 1C file in four guided steps, edits a store page section by section; a store manager switches role and submits up to five products that land in the owner's queue.

FIRST VIEWPORT: Sidebar (wordmark, grouped nav with moderation count); top bar with page title and the role switcher; Обзор content: attention list left, quick actions and store table right.

FORM: Extension of the established world (no roll; DESIGN.md governs).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
